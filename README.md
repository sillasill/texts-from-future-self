# Texts From Your Future Self

A single text message from your future self, sent back to the present day. It opens like a grand warning from decades ahead and then deflates into the most ordinary culprit imaginable — the kind of everyday object you sit on without a second thought — before landing the punchline a second time as a quiet confession. No setup, no context, just the message as it would arrive on your phone.

## Run it

```sh
node main.ts
```

This writes the text to `/output/entry.txt`.
